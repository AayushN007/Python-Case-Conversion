# Python Case Conversion

A simple Python program to convert the case of letters using ASCII values.

## Features
- Converts lowercase letters to uppercase
- Converts uppercase letters to lowercase
- Keeps numbers and special characters unchanged

## Concepts
- Strings
- Loops
- ASCII values
- `ord()` and `chr()`

## File
- `CaseConversion.py`

## How to Run

```bash
python CaseConversion.py
